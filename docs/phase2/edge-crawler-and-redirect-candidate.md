# Cloudflare edge crawler/redirect candidate — live rules verified separately

`node scripts/build-edge-crawler-policy.mjs` emits **candidate rule objects only**. It never changes Cloudflare. The two explicitly approved rules were installed separately via the operations-token API on October 18, 2026; the verified-search skip candidate remains **uninstalled**. No PR was merged.

## Why these rules

- During 2026-10-17 00:00–10:00 UTC, Cloudflare adaptive analytics grouped 65,544 HTTP 308 responses on `www.wetbulb35.com`: 64,358 had a ShapBot user agent. Joining every grouped path to the checked-in historical-redirect registry found **one request** for a different-destination alias, and **none** among ShapBot requests. Edge request estimates are not the billable Worker counter.
- The registry nevertheless contains 129,080 historical alias sources. A blanket append-slash rule would silently intercept many valid historical routes if someone requests them later. The candidate targets 18 known country-first prefixes that have **zero** historical alias-source intersections, covering 60,012 current city routes and 40,791 of those 64,358 observed ShapBot redirects. After ShapBot is blocked, expected redirect savings are much smaller and must be remeasured.
- The ShapBot block matches its claimed user-agent, including the small unverified fraction; Cloudflare classified 64,370 of 64,446 ShapBot-UA requests (2026-10-18 00:00–02:50 UTC) as verified `AI Search`. It also explicitly excludes verified `Search Engine Crawler` traffic. User agents can be spoofed or changed, so this is not a complete bot-identity policy. The separate search-engine rule skips **only** rate limiting, not WAF protections; it must be reviewed against the *existing* zone rate rules before activation. It does not impose a crawler rate limit itself.

The zone contained no custom WAF or dynamic-redirect entrypoints before these writes; the zone ruleset inventory was privately backed up under `/home/laclaw/.local/share/wetbulb35/cloudflare-edge-backups/20261018T202350Z` before the redirect change. The redirect entrypoint was created disabled, parser-validated, updated to exclude ShapBot, enabled, read back as one enabled rule, and snapshotted under `/home/laclaw/.local/share/wetbulb35/cloudflare-edge-backups/20261018T202838Z`.
2. **WAF test:** Cloudflare Trace with verified ShapBot and verified Google/Bing requests (or actual known-verified traffic where Trace cannot simulate verification). Confirm the ShapBot block executes before either Worker, and that the search-engine Skip affects only the intended rate-limiting phase. Free AI Crawl Control can also block ShapBot by user agent, but that alternative is not the same as verified-WAF matching; choose one mechanism, not duplicate blocks.
3. **Redirect live tests:** Cloudflare Trace returns 403 for this token, so the enabled rule was tested with live GET/HEAD requests while Workers Free was exhausted. `/wetbulb-temperature/germany/bavaria/munich` returns an edge 308 to its slashful canonical route even while ordinary Worker-backed pages return 429. Query strings and HEAD preserve targets; slashful routes, APIs, assets, a sampled legacy alias, the apex hostname and another country remain unmatched (429 during quota exhaustion). ShapBot remains blocked with 403 on the matched slashless path. Encoded paths and double slashes may be normalized upstream: a double-slash URL still received a 308, and one encoded slash retained `%2F` in the target. No HSTS response header was present on the edge 308; the zone-level HSTS setting is off. Destination Worker HSTS and actual 200/404 behavior cannot be verified until its daily request budget resets.
4. **404 tradeoff:** a *nonexistent* slashless path beneath an allowlisted country gets an extra edge 308 before the destination's eventual 404. No source in the 129,088 known historical alias-source registry lies under any of the 18 prefixes, but unknown/malformed URLs are not guaranteed identical. This narrow, reversible difference was accepted in order to avoid hijacking real old routes; do not generalize to a blanket rule.
